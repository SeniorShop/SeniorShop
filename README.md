# SeniorShop 
Магазин, демонстрирующий применение ООП для работы со складами, продажами, поставками, пользователями и финансовой отчетностью. 
# 1. Суть проекта
Проект демонстрирует применение объектно-ориентированного стиля программирования для создания полнофункциональной системы, выполняющая свои поставленные задачи. 
# 2. Цель проекта
Проект создан с целью показа применения объектно-ориентированного программирования в реальном бизнес-контексте. В ходе разработки были использованы ключевые концепции ООП:
```
    1) Инкапсуляция - скрытие внутренней логики работы классов
    2) Наследование - иерархия пользователей (SuperAdmin, Admin, User)
    3) Полиморфизм - виртуальные методы и переопределение поведения
    4) Абстракция - использование абстрактных классов для различных компонентов системы
```
# 3. Примененные технологии
```
  1) C++ - основной язык, на котором базируется сам проект.
  2) Стандарт - используется С++20 стандарт для работы с std::format, дополнительными опциями std::chrono.
  3) CMake - система сборки проекта, используется в первую очередь для сборки проекта нв двух системах: Linux и Windows.
  4) Компилятор - для компиляции проекта используются два инструмента компиляции программы: g++ и MSVC.
```
# 4. Кроссплатформенность
```
Проект работает на двух системаа: Linux и Windows
Другие системы не поддерживаются
```
# 5. Основные классы/структуры и их типы
Система авторизации и входа в систему: 
```
  1) AuthSystemUser - класс для авторизации от лица супер-администратора.
  2) User / SuperAdmin / Admin / RegularUser - классы для основных статусов пользователей.
  3) Captcha - класс для работы капчи, используется в качестве защиты от ботов.
  4) Logger - класс для записи данных в лог-файл, содержащий информацию о входе в систему от лица
  того или иного пользователя с указанной датой и временем.
  5) LoginSystem - класс для входа в систему.
```
Управление складом: 
```
  1) Storage - основной класс, реализующий склад для основные операций:
  1.1: Добавление товара
  1.2: Изменение цены товара
  1.3: Списание товара со склада
  1.4: Удаление товара
  1.5: Изменение товара по артикулу
  1.6: Пополнение количества товара по артикулу
  2) Product - структура, хранящая в себе информацию о товаре (название,
  артикль, поставщик, категория, цена и т.д.).
  3) SupplyManager / Supply / SupplierManager - управление поставками и поставщиками.
```
Продажи и акции: 
```
  1) SaleService - класс-сервис по управлению товарами и корзинами.
  2) SaleController - класс для контролирования выполнений операций: оплата, покупки
  3) Cart - класс, реализующую корзину с товарами.
  4) CartItem - класс, реализующий добавление товара в корзину. 
  5) SellActiv - класс для работы с акциями.
```
Управление персоналом: 
```
  MethodSuperAdmin - класс для редактирования персонала от имени супер-администратора.
```
Отчёты: 
```
  Check - класс для хранения отчетов о продажах, чеках, списаниях, логах. 
```
# 6. Требования к запуску проекта
```
  1) Должен быть минимум С++20 стандарт для работы проекта.
  2) Должен быть Linux или Windows для запуска, другие ОС не поддерживаются.
  3) Должна быть система сборки CMake, чтобы проекта запускался на двух ОС.
```
# 7. Как запускать проект
1) Для скачивания проекта с репозитория можно использовать несколько вариантов: 
1.1: Установить проект в виде ZIP формата.
1.2: Использовать Git систему контроля версий в консольном варианте:
```
git clone https://github.com/SeniorShop/SeniorShop.git
```
Можно использовать стандартный терминал в Linux или PowerShell в Windows.
С условием, если Git присутствует в системе!
2) Запустить проект на двух системах можно несколькими способами
```
2.1: Открыть в проекте уже существующий ZIP формат файла проекта.
```
В Windows системах больше используется IDE вроде VS 2022/2026 для запуска 
проекта. Достаточно выбрать CMakeLists.txt файл для открытия проекта и запустить F5
```
2.2: Запустить проект через g++ компилятор.
```
В Linux и Windows для запуска проекта можно использовать g++ компилятор, 
который работает на двух системах одинаково,с условием если g++ компилятор
уже есть. 
Главное быть в текущей директории проекта. В Windows проект можно запустить через: 
```
g++ -std=c++20 src/*.cpp -o outputfile.exe
```
В Linux работает почти также: 
```
g++ -std=c++28 src/*.cpp -o outputfile
```
Далее просто запуск проект:
```
./outputfile
```
